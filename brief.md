Create a **premium, minimal, mobile-first landing page and lead capture form** for **BhaGoMo iRide**, an electric scooter rental service at Delhi Metro stations.

### Design Direction
- **Aesthetic:** Modern mobility-tech, editorial minimalism, premium UI/UX, high visual fidelity.
- **Typography:** Bold display headings, clean sans-serif body, strong visual hierarchy, exceptional readability.
- **Layout:** Spacious, structured grid, generous whitespace, precise alignment, subtle rounded corners.
- **Animations:** GSAP-style micro-interactions, staggered fade-ins, smooth easing, subtle parallax, animated focus states, responsive button hover, polished transitions.
- **Performance:** Lightweight, accessible, responsive, 60fps animations, reduced-motion support.

### Page Structure
**Hero:** "METRO SE MANZIL TAK, BHAGO."

Subheading: "Your Metro journey ends here. Your next ride starts with BhaGoMo iRide."

Primary CTA: **Get Started**

### Lead Form
Create a clean, single-page form with:
1. **Rider Name** — Text input
2. **Phone Number** — 10-digit validation
3. **Metro Station** — Dropdown: IP Extension, Mandi House, Dwarka Sector 14, Nehru Enclave, ITO, Guru Dronacharya
4. **Plan Interested In** — Dropdown: 2, 4, 6, 8
5. **Comments** — Optional textarea
6. **Contact Consent** — Required checkbox

**Submit CTA:** "Let's Ride →"

### Functionality
- Inline validation and clear error states.
- Loading, success and failure states.
- Smooth scroll to form from hero CTA.
- Keyboard accessibility and touch-friendly controls.
- Google Sheets integration for lead storage and a basic summary dashboard showing total leads, station-wise enquiries and plan-wise interest.
- Prevent duplicate submissions.
- Do not fabricate pricing, availability or rental terms.

### Execution Standards
**Design keywords:** Awwwards-inspired restraint, pixel-perfect spacing, optical alignment, refined typography, intentional motion, progressive disclosure, frictionless UX, responsive composition, polished interaction design.

Keep the experience **simple, fast, beautiful and conversion-focused**. No unnecessary sections, excessive animations, visual clutter or generic templates. Every element must serve usability, clarity or conversion.

**Deliver a fully functional, production-ready responsive page, not just a visual mockup.**
